# ChatJS

ChatJS provides reusable foundations for composing AI applications. Its reference demo combines capabilities that other applications can select according to their needs.

## Language

**Core**:
The shared contracts and baseline behavior required by ChatJS applications. The core does not imply that every feature of the reference demo is mandatory.

**Capability**:
A selectable unit of application behavior with the requirements needed to make it work. Capabilities can share requirements and can be composed into larger experiences.

**Preset**:
A named selection of capabilities and their initial configuration. A preset describes a starting application, rather than a separate implementation of its features.

**Feature bundle**:
A convenient selection of building blocks, capabilities and shared requirements that together provide a complete feature. Its constituent pieces remain available for finer-grained composition.

**Reference demo**:
The existing ChatJS demo with its resolved default configuration, used to define the full reference application experience.
