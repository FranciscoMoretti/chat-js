Package parallel responses as an optional chat plugin. Select `parallel-responses` to compare replies, retry unfinished comparisons, and continue from a chosen branch. Existing comparisons use the same table and operation IDs.

Create selects the single-model `model-picker` plugin by default. Choose No picker to omit the selector UI or Parallel Responses to install the comparison picker.
