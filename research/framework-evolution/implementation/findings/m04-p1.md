# P0/P1 implementation: independent conversation views

Scope: the approved P0/P1 slice of [the migration plan](../plans/m04-composable-ui-plan.md), against main `18db694b`. P2–P9 are not implemented. No Eve migration, UI component factory, CLI-template migration, merge, or deployment.

## Implemented boundary

- `ConversationView` is an ordinary provider under the existing runtime binding. Named view controllers retain their own cursor and followed run across route unmounts; the runtime retains the canonical tree and execution. Shared runtime snapshots are referenced rather than copied into another mutable message store. Disconnecting a view releases its subscription and invalidates pending selection work without stopping execution.
- Existing message lists, message actions, retry, parallel cards, navigation, suggested actions and composers use view selectors/commands. Explicit message IDs remain message scope; they do not resolve through a global selected transcript. `Thread.regenerateRun` returns the exact run and defaults to no canonical following; existing `regenerate` behavior is preserved.
- Existing `ChatInputProvider` keeps draft/model/tool/attachment state independent. Draft storage is namespaced by caller, stable conversation/provisional scope and view. Restoration precedes editor mounting. Upload preparation and completion check mount, selection and consumed-draft generations. Pending batches are tracked separately so an old completion cannot clear a newer batch's loading state.
- The existing resizable layout and document panel live at workspace scope. Opening a document captures the source runtime, view, message, model and read-only state. Toolbar commands retain that origin after navigation/unmount. A workspace subscription continues document stream updates after the source view disappears. Inline previews use streaming content only when their origin matches. Changing the panel target remounts its local editor/version/save state.
- No P2 split into public ComposerInput/ComposerSubmit/ModelPicker modules is included. The existing components remain the reference UI. Exact document revision/persistence semantics remain P4 work; this slice fixes origin routing and lifetime.

Next MCP reported no compilation or runtime errors. The actual `/api/chat` model call failed with `GatewayAuthenticationError`; the shared development credentials also returned Unauthorized for the model catalog. Credential refresh was requested without exposing secrets. Live successful model completion remains unverified.

## Review and corrections

Independent spec and standards reviews found and drove fixes for unstable provisional draft storage, stale attachment insertion, stale upload cleanup clearing a newer batch, and inline document previews reading another origin's streaming content. Removed the now-unused artifact stream callback API. Browser testing additionally exposed the initial empty editor callback racing draft restoration, which is fixed by restoration before editor mount.

The PR remains a draft. The broader migration is not complete, and the credential-dependent live-model gate must not be reported as passing.
