# ChatJS homepage

The homepage uses Canopy’s flat, pannable grid. The opening prioritizes chat capabilities from Create. A tile changes the selection carried by **Build your app**. **Create** and **New +** open the default configurator. The footer credits the author and links to the source.

Run `bun dev:site` and `bun test:visual:home` to check the grid at phone, tablet, and desktop sizes, and exercise the quickstart, links, and block toggles.
