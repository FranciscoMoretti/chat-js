---

ChatJS renders Markdown in assistant messages with Streamdown. To request a particular format, edit the [agent instructions](/customization/prompts). To change how a response appears, start in `components/ai-elements/response.tsx`.

## Code blocks

A language tag on a fenced block tells the renderer which syntax to highlight. For example, an assistant can return this Markdown.

````markdown
```typescript
function greet(name: string) {
  return `Hello, ${name}!`;
}
```
````

## Renderer and themes

The `Response` component passes the `code`, `math`, and `mermaid` plugins to Streamdown. These handle highlighted code, mathematical notation, and diagrams as the reply arrives. Keep those plugins in the component if you customize its wrapper or classes.

For changes to code styling, see the [Streamdown documentation](https://streamdown.ai). For colors shared with the rest of the app, see [Theming](/customization/theming).
