<Callout type="warning">
  **ChatJS 1.0 is in alpha.** You can build apps with it, but APIs,
  configuration, and generated code may change substantially before the stable
  release. Use `chat-js@alpha` to try the current alpha.
</Callout>

`chat-js` gets you from zero to a running ChatJS app in one command. No installation required — run it directly with `npx`:

```bash
npx chat-js@alpha create my-app
```
