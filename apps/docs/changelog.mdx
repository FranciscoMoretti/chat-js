## November 2026 · ChatJS 1.0 alpha

Use `chat-js@alpha` to scaffold the 1.0 alpha. This release series changes the agent runtime and the layout of generated apps. Existing apps need a source migration or a fresh scaffold to adopt these changes.

| CLI release | What changed |
| --- | --- |
| `1.0.0-alpha.8` | Generated apps use branch IDs for ChatJS branches. Plugins register through conventional files such as `chat-server.ts`. The CLI installs from registry `0.2.0-beta.9`. [Plugin API](/reference/plugin-api) |
| `1.0.0-alpha.7` | Updates the registry for Deep Research installation and workspace report publication. [Deep Research](/tools/deep-research) |
| `alpha.5` and `alpha.6` | Adopts the ChatJS build of EVE 1.1 and ships the shared gateway runtime as editable app source. [Architecture](/core/architecture) |
| `1.0.0-alpha.4` | Pinned the gateway contract and registry used by fresh installations to fix a scaffold type-check failure. |
| `1.0.0-alpha.3` | Generates native EVE agents from builder selections. EVE runs channels, tools, approvals, and sandboxes. ChatJS handles web authentication, resource access, and file publication. [Project structure](/project-structure) |
| `alpha.0` through `alpha.2` | Introduces the `chat-js` 1.0 alpha CLI and publishes the dependencies needed to install outside the monorepo. [Quickstart](/quickstart) |

For individual fixes and release numbers, see the [CLI changelog](https://github.com/FranciscoMoretti/chat-js/blob/main/packages/cli/CHANGELOG.md) and [registry changelog](https://github.com/FranciscoMoretti/chat-js/blob/main/packages/registry/CHANGELOG.md).

## March 2026

ChatJS added an Electron desktop companion and a model comparison interface. For current packaging targets and comparison behavior, see [Desktop deployment](/deployment/desktop) and [Conversations](/core/conversations#parallel-responses).

## February 2026

The initial ChatJS release, formerly Sparka AI, built on [Vercel AI Chatbot](https://github.com/vercel/chatbot). Early releases introduced the scaffolding CLI, multi-provider chat, OAuth sign-in, stream recovery, document editing, web search, code execution, image and video generation, and browser tests.
