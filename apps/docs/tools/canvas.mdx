---
title: Documents & Files
description: Create files in EVE's sandbox and open immutable published results
---

Documents are files in the agent's native EVE sandbox. Ask the agent to create a report, script or spreadsheet, then publish the finished file into the conversation.

## Installation

Enable EVE's native default tools and install file publication with persistent storage:

```bash
bunx chat-js@alpha add attach-workspace-file --storage-provider vercel-blob
```

Use Docker or Vercel Sandbox when your task needs native Python or Node processes. The simulated just-bash environment can write text files but cannot run those processes. See [Sandboxes](../deployment/sandboxes).

## Creating a file

For example, ask: "Create a sample budget spreadsheet as a CSV file in your sandbox and publish it for download."

The agent uses native tools to write the file, then calls `attach_workspace_file`. ChatJS stores an immutable snapshot and displays a download card. Publication is limited to files inside the sandbox workspace, up to 32 MiB each. Access follows the owning ChatJS conversation.

## Optional viewers

Downloads work without a viewer. Install richer presentation independently:

```bash
bunx chat-js@alpha add image-viewer video-viewer spreadsheet-viewer
```

The spreadsheet viewer opens CSV, TSV and XLSX files in a read-only preview. You can select worksheets and inspect cell values. It does not recalculate formulas or reproduce workbook formatting and charts. The original file remains downloadable.

## Changing a file

Ask the agent to revise an earlier file. The `import_file` tool, included with `attach-workspace-file`, copies the authorized snapshot into the current sandbox. The agent edits that copy with native tools and publishes a new file. Previous downloads remain unchanged.

There is no manual editor, revision chain, version picker or restore button. To reuse an earlier result, identify that file in the conversation and ask the agent to import it. You can also download it, edit it elsewhere, and upload the result when attachment uploads are installed.

See [Code Execution](./code-execution) for examples, limits and file import behavior.
