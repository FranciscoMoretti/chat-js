EVE includes `web_search` for supported model providers and `web_fetch` for reading a known URL. You can control both in Create → Agent → Tools. See [EVE’s built-in tools](https://eve.dev/docs/concepts/built-in-tools).

## Add a search connection

Choose Tavily, Firecrawl, or both in Create → Agent → Connections. In an existing app, run the corresponding command from the project root:

```bash
eve add connection/tavily
eve add connection/firecrawl
```

- [Tavily](https://eve.dev/integrations/tavily) exposes search, extraction, crawling, and URL mapping. Its registry setup uses Vercel Connect for per-user sign-in.
- [Firecrawl](https://eve.dev/integrations/firecrawl) exposes search, scraping, mapping, crawling, and other operations. Set `FIRECRAWL_API_KEY` server-side and follow the connection’s approval prompts.

EVE discovers the tools on each configured connection. ChatJS displays their results in the conversation’s tool activity. The assistant can cite links in its answer.

[Deep Research](./deep-research) can use the same search and retrieval capabilities as the parent agent. Install whichever connections fit your app.
