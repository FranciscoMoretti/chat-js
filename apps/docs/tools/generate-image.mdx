## Select during creation

```bash
npx chat-js@alpha create my-app --yes --image-generation-tool generate-image
```

Interactive creation offers the built-in gateway implementation or an external registry item when you enable image generation. The built-in implementation uses your selected [gateway](../gateways/overview) and durable [file storage](../storage). Configure their credentials and an image-capable default model before running it.

## Installation

In an existing ChatJS app with registry-based image tools:

```bash
npx chat-js@alpha add generate-image
```

Set `ai.tools.image.default` in `chat.config.ts`. Installation makes the tool available. There is no separate `enabled` flag.

You receive `chatjs/tools/generate-image/tool.ts`, `renderer.tsx`, and `chatjs.json`. Sync generates the registration and credential configuration. Fresh apps without image generation receive neither this implementation nor its renderer. Shared image viewing and storage helpers remain available to other app features.

## Behavior

The tool accepts a prompt and returns `{ imageUrl, prompt }`. It supports image creation and editing using attachments or the previous generated image. It uploads results through the configured Files SDK storage and reports provider cost in the final tool receipt through `executeWithToolUsage` and its usage accumulator (`usage.addCostUsd()`).

### Model selection

If the selected chat model supports image output, the tool uses it. Otherwise, it uses `ai.tools.image.default`. The gateway supplies either a dedicated image model or a language model that supports image output.

```ts title="chat.config.ts"
ai: {
  tools: {
    image: { default: "google/gemini-3-pro-image" },
  },
}
```

### Editing images

Ask for an image, then request a change such as "Add a lake in the foreground." The tool can use the previous generated image and attached images as edit inputs. The previous-image helper recognizes the built-in `imageUrl` output. It ignores results from tools that use a different output shape.

While generation is running, the renderer shows a loading state with the prompt. On completion, it displays the generated image and copy controls.

## External implementations

```bash
npx chat-js@alpha create my-app --yes \
  --image-generation-tool https://example.com/r/image-tool.json
```

Declare `slot: "generateImage"` in your registry metadata and installed descriptor. Export a native EVE tool with your own input/output schemas. A renderer is optional. External tools do not need a gateway image default. Declare provider credentials in `envRequirements` for the CLI checklist and app validation. Only one item can occupy this selection.

The installed implementation reads the native session model selection and imports ChatJS helpers for image context, model pricing, and authorized file upload. The built-in previous-image helper recognizes an `imageUrl` result. Other result schemas work as tools but do not participate in that helper automatically. See [Authoring Tools](./authoring).
