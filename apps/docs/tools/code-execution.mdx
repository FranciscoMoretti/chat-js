## Native execution

New ChatJS agents enable EVE's default tools, including `bash`, `read_file`, `write_file` and `edit_file`. Use `bash` to run Python, Node or other commands available in the agent's sandbox. ChatJS displays the command, stdout, stderr, exit code and native background-process status.

Choose Automatic, Docker or Vercel Sandbox in the builder's Agent tab. Automatic can fall back to just-bash in development; that simulated environment cannot run native Python or Node processes. See [Sandboxes](/deployment/sandboxes).

Install dependencies using normal shell commands or configure the native EVE sandbox image. ChatJS does not install Python packages, rewrite notebook syntax, print special variables or capture charts automatically.

## Attach a generated file

Install `attach-workspace-file` with persistent storage:

```bash
bunx chat-js@alpha add attach-workspace-file --storage-provider vercel-blob
```

For example, the agent can use `bash` to run:

```bash
python3 - <<'PY'
import csv
with open('/workspace/budget.csv', 'w') as file:
    csv.writer(file).writerows([['Item', 'Cost'], ['Hosting', 120]])
print('Created /workspace/budget.csv')
PY
```

Then call `attach_workspace_file` with `{ "path": "/workspace/budget.csv" }`. The tool copies a snapshot into application storage and returns an authenticated file reference. Files must be inside the sandbox workspace and at most 32 MiB. ChatJS checks access to the owning web conversation; subagents return paths to the parent for publication. Native Slack file delivery remains an EVE channel concern.

For charts, save an image explicitly, such as `plt.savefig('/workspace/chart.png')`, then publish that file. There is no special `chart` dictionary protocol.

## Optional viewers

Downloads work without a viewer. Install viewers independently:

```bash
bunx chat-js@alpha add image-viewer video-viewer spreadsheet-viewer
```

The spreadsheet viewer opens uploaded and published CSV, TSV and XLSX files. It displays read-only cell values and worksheet selection, with previews limited to 5,000 rows and 200 columns. It does not recalculate formulas, render Excel charts or preserve workbook formatting. The original file remains downloadable.

## Revise a file through chat

The `attach-workspace-file` item also installs `import_file`. When you ask for a change to an earlier artifact, the agent imports its exact `fileId` and filename into the current EVE workspace, edits that copy using native tools, and publishes a new file. The original snapshot stays unchanged. Import works even when the original sandbox is gone, provided the file is still stored and referenced by the current conversation.

Import checks the current conversation owner's authority before reading storage. It accepts files up to 32 MiB and does not grant access to files from other conversations. If a file is ambiguous or unavailable, identify it or upload it again. You can also download a file, edit it in another application and upload the result when uploads are installed.

Viewers stay read-only. New results are separate files in the conversation, without automatic version merging or an in-app editor.

## Accounting

Native command execution do not create a fixed ChatJS tool charge. Model usage and infrastructure provider charges remain separate. EVE owns sandbox lifecycle, cancellation and background processes.
