title: Theming

---

ChatJS uses standard [shadcn theming](https://ui.shadcn.com/docs/theming) with CSS variables. Set your palette once and components can use the same foreground, background, and border colors.

This also applies to [AI Elements](https://elements.ai-sdk.dev/) components since they’re shadcn-compatible and read the same CSS variables.

## Quick start

1. Open `app/globals.css`
2. Edit the CSS variables in `:root` (light) and `.dark` (dark)

## Generate a theme

Use the [shadcn theme generator](https://ui.shadcn.com/create) to create a palette, then copy the CSS variables into `app/globals.css`.

To change the typeface, follow [Fonts](/customization/fonts). For icons and social previews, see [Branding](/customization/branding).
