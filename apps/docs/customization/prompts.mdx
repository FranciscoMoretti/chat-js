## Change the signed-in assistant's instructions

Edit `systemPrompt()` in `lib/ai/prompts.ts`. The native EVE entry in `agent/instructions/chat.ts` calls this function for account sessions. For example, a support app could ask the assistant to give readers a way to check each answer.

```ts title="lib/ai/prompts.ts"
export const systemPrompt = (): string =>
  `You help developers use our product.
Give a short answer, then a concrete step the reader can use to verify it.
If a version or error message would change the answer, ask for it.`;
```

For how Markdown, fenced code, and diagrams appear in responses, see [Syntax highlighting](/core/syntax-highlighting).

Start a signed-in chat and try the same question before and after your change. If you need instructions that depend on the session, use an instruction entry under `agent/instructions/`. See [EVE instructions](https://eve.dev/docs/instructions).

## Choose the right scope

| Scope | Where the instructions come from |
| --- | --- |
| Signed-in conversations | The base prompt above, plus any applicable EVE instruction entries. |
| Project conversations | The optional Projects plugin contributes the project's saved instructions. Users can edit them in the project UI. See [Projects](/plugins/projects). |
| Guest conversations | The optional Guest Chat plugin supplies its own session instructions in `chatjs/plugins/guest-chat/guest-policy.ts`. See [Guest Chat](/plugins/guest-chat). |
| A particular tool | Edit the tool's description or input schema to explain when to call it and what inputs it accepts. See [Authoring tools](/tools/authoring). |
