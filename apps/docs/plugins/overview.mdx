## Chat

| Plugin | What it adds |
| --- | --- |
| [Projects](/plugins/projects) | Organize conversations and share instructions across related chats |
| [Model Preferences](/plugins/model-preferences) | Choose which models appear in your picker |
| [Sharing](/plugins/sharing) | Publish read-only conversations with revocable access |
| [Guest Chat](/plugins/guest-chat) | Let visitors try disposable text conversations |
| [Desktop](/plugins/desktop) | Connect an Electron companion through browser sign-in and session transfer |
| [Credits](/plugins/credits) | Gate spending and debit user balances from recorded usage |
| [AI Titles](/plugins/ai-titles) | Automatically name new chats |
| [Search](/plugins/search) | Find chats by title and conversation text |
| [Feedback](/plugins/feedback) | Collect private ratings on assistant messages |
| [Follow-up Suggestions](/plugins/followup-suggestions) | Generate related questions after an answer |
| [Attachments](/plugins/attachments) | Upload images and PDFs from the composer |

## File viewers

Install `image-viewer`, `video-viewer`, or `spreadsheet-viewer` to open published workspace files directly in chat. Each viewer handles its own formats. See [Documents & Files](/tools/canvas#optional-viewers) for installation and spreadsheet support.

| [MCP](/plugins/mcp) | Connect external tools with connector settings and OAuth |
