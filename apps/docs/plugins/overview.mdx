Choose a plugin to see its installation steps, usage, configuration, and storage requirements. New to plugins? Start with [Using plugins](./using-plugins).

## Chat

| Plugin | What it adds |
| --- | --- |
| [Projects](./projects) | Organize conversations and share instructions across related chats |
| [Model Preferences](./model-preferences) | Choose which models appear in your picker |
| [Sharing](./sharing) | Publish read-only conversations with revocable access |
| [Guest Chat](./guest-chat) | Let visitors try disposable text conversations |
| [Desktop](./desktop) | Connect an Electron companion through browser sign-in and session transfer |
| [Credits](./credits) | Gate spending and debit user balances from recorded usage |
| [AI Titles](./ai-titles) | Automatically name new chats |
| [Search](./search) | Find chats by title and conversation text |
| [Feedback](./feedback) | Collect private ratings on assistant messages |
| [Follow-up Suggestions](./followup-suggestions) | Generate related questions after an answer |
| [Attachments](./attachments) | Upload images and PDFs from the composer |
