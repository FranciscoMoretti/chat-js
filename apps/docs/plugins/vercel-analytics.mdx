This plugin mounts the Vercel Analytics client in your app's layout.

## Installation

```bash
bunx @chat-js/cli@latest add vercel-analytics
```

The CLI installs the client source and generates its layout registration. This plugin adds no database tables.

## Usage

The generated layout renders the `Analytics` component. Configure the corresponding service in your Vercel project to view its data.

## Customization

Edit `plugins/vercel-analytics/component.tsx` to customize the component. Its `client-plugin.ts` exposes the layout contribution. It does not register server routes or require a ChatJS enable flag.

See [Using plugins](../core/plugins) for installation behavior and the [Plugin API](../reference/plugin-api#client-placements) for the layout contract.
