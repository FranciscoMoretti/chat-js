---
title: Chat Layout
description: "Change the width of the chat transcript and composer together, and choose where notices and other content appear as messages scroll."
---

The chat screen has two layouts. An empty chat shows the welcome view with its composer. Once it has a transcript, the messages scroll above a footer containing notices and the composer. Both layouts are composed in `components/chat/chat-conversation-screen.tsx`.

## Widen the conversation

Change both width limits to keep the messages and input aligned.

1. In `components/chat/chat-conversation-screen.tsx`, find `MessageScrollerContent`. Change `max-w-3xl` to your desired width, such as `max-w-4xl`. Keep `mx-auto w-full` to center it and let it shrink on narrow screens.
2. In `components/chat/chat-conversation.tsx`, apply the same width to `ChatConversationFooter`.
3. Open a chat with enough messages to scroll. Check that the transcript and composer line up on desktop and that the composer stays visible on a narrow screen.

The welcome composer lives in `ChatWelcomeView`. Edit `components/chat/chat-welcome-view.tsx` if you also want to change its placement before the first message.

## Place content around the transcript

`ChatConversationScreen` accepts React nodes for these positions. Choose one according to whether the content should scroll with the messages.

| Prop | Position |
| --- | --- |
| `header` | Above the welcome view or conversation body |
| `leading` | Inside the scroller, before the transcript |
| `trailing` | Inside the scroller, after the transcript and thinking indicator |
| `notices` | Above the composer in the conversation footer and below the composer in the welcome view |

Keep the supplied composer and recovery controls connected when changing their placement. For an action that belongs to a single message or tool result, use the [plugin slots](/reference/plugin-api) or a [tool renderer](/cookbook/tool-part).
