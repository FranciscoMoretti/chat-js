---

ChatJS uses two component libraries/registries: [shadcn/ui](https://ui.shadcn.com) and [AI Elements](https://elements.ai-sdk.dev/). Both are shadcn-style, Tailwind-friendly, and theme via the same CSS variables in `app/globals.css`.

## shadcn/ui components

[shadcn/ui](https://ui.shadcn.com) components are added to `components/ui` and use your theme CSS variables from `app/globals.css`.

```bash
bunx shadcn@latest add <component>
```

## AI Elements components

AI Elements is a shadcn-compatible component registry focused on AI UX ([docs](https://elements.ai-sdk.dev/)). In this repo, AI Elements components live in `components/ai-elements`.

```bash
bunx ai-elements@latest add <component>
```

After installing, import from `@/components/ai-elements/...` and style them like any other component.

## Keep app-specific behavior in a wrapper

When an installed component needs chat-specific behavior, wrap it in the app and import the underlying primitive. For example, `components/chat/chat-workspace.tsx` composes the sidebar provider and inset from `components/ui/sidebar.tsx`. The wrapper sets the chat layout defaults and the primitive remains easy to compare with upstream. See [Chat layout](/cookbook/chat-layout).
