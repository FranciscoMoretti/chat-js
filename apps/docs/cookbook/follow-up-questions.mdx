---
title: Follow-up Questions
description: Customize generation and display through the Follow-up Suggestions plugin
---

Use the [Follow-up Suggestions plugin](../plugins/followup-suggestions) to add three to five related questions after a completed answer. This recipe shows where to customize its generation and rendering.

## Prerequisites

Install the plugin, apply its database migration, and enable `ai.tools.followupSuggestions.enabled` in `chat.config.ts`. Select a model available through your gateway with the `default` option.

## Customize generation

1. `agent/hooks/followup-suggestions.ts` registers the plugin's native EVE hook.
2. `plugins/followup-suggestions/followup-hook.ts` collects the current exchange and claims the completed turn before making a model call.
3. `plugins/followup-suggestions/generate-suggestions.ts` generates the questions using the configured model and core usage accounting.
4. `plugins/followup-suggestions/followup-queries.ts` stores the result in `EveFollowup` with its session, turn, and completion-event identity.

Edit the generation prompt to change the style of questions. Keep the durable claim before the paid call, preserve completion identity, and retain model usage accounting. The output schema in `suggestion-output.ts` accepts three to five nonempty suggestions of at most 80 characters each.

## Customize display

`plugins/followup-suggestions/use-followups.ts` matches the completed answer and reads stored results with bounded polling. Suggestions are persisted separately from the native transcript and are displayed after generation finishes.

Edit `followup-suggestions-view.tsx` to change their presentation. The plugin's `Suggestions` contribution passes selected text to core's existing send/compare flow. Generated questions become conversation input only when selected.

## Preserve cleanup

The plugin's `chat.ts` removes results for deleted native sessions inside the existing deletion transaction. Keep this callback when changing storage so deleting one branch preserves surviving results and late generation cannot recreate a deleted claim.

See the [Plugin API](../reference/plugin-api) for the lifecycle and UI contracts.
