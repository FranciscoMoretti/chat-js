---
title: Explicit Tool Selection
description: "Trace a tool choice from the chat composer through the authenticated gateway to the EVE instructions and tools available for that turn."
---

The composer can let a signed-in user request one supported tool before they send a message. ChatJS validates the selected tool at admission and passes it to EVE as authenticated turn metadata. The EVE tool-selection hook then narrows the available tool set for that turn.

## Flow

```mermaid
flowchart LR
    UI[Composer selection] --> Request[ChatJS creation or message request]
    Request --> Gateway[Authenticated EVE gateway]
    Gateway --> Metadata[Native session attributes]
    Metadata --> Hook[Tool-selection hook]
    Hook --> Tools[Allowed EVE tools]
```

`lib/eve/message-tool-selection.ts` stores the selected UI tool in message metadata for recovery and copy operations. `lib/eve/selected-tools.ts` expands a grouped selection into its allowed native tools. `agent/hooks/tool-selection.ts` reads the authenticated selection at turn start.

For account sessions, the hook validates the selection against the configured tools. Guest sessions support text chat only and run without a selected tool.
