This page explains the URL routing structure used in ChatJS.

## Route Types

| Route Pattern | Description |
| --- | --- |
| `/` | Home page, draft chat (not yet persisted) |
| `/chat/:chatId` | Standalone chat page |
| `/share/:id` | Public shared chat page (read-only) |
| `/project/:projectId` | Project page, draft chat within project |
| `/project/:projectId/chat/:chatId` | Validates project membership and redirects to the conversation |

## Reading the active conversation

Shared chat components use `useActiveConversationId()` from `@/components/chat/chat-navigation`. In a Next.js app it reads the `[chatId]` route parameter. An embedded chat supplies its conversation ID through `ChatNavigationContext`. Public share links use a separate `[id]` parameter.

Projects reads `[projectId]` in its own sidebar component. For a conversation with project membership, Projects provides `parentHref` through its chat integration so deletion returns the user to the project.
