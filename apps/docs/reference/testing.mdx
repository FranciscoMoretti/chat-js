## Unit tests

Vitest runs tests alongside their source. From an app directory, run the full unit suite or pass a filename to Vitest. The app's `vitest.config.ts` excludes Playwright's `*.e2e.ts` files.

```bash
bun run test:unit
```

In the ChatJS repository, run a targeted test from the reference app. For example, this exercises the connection settings used by Drizzle.

```bash
cd apps/chat
bunx vitest run lib/db/connection.test.ts
```

## Browser tests

Run the app's Playwright script from the app directory. For a fresh development machine, install Chromium first.

```bash
bunx playwright install chromium
bun run test:e2e
```

Playwright reads `.env.local`. Its web server starts the app’s `dev` script with the scaffold’s package manager on the configured `PORT` (3000 by default), or reuses a running server locally. The default config selects tests by each project's `testMatch`. When adding a browser scenario, check that it appears in the list for the intended project.

```bash
bunx playwright test --list
```

The repository also has reference-only browser scenarios, including live tool checks. See [Registry testing](/registry/testing) for the registry and visual suites.

## Agent behavior

Use [evaluations](/reference/evaluations) to check what an agent says or which tools it calls across repeated runs. Use browser tests for interactions such as selecting a model or reopening a chat.

## Optional developer tools

Inside your generated app, install the developer tool you want to use. These versions match the scaffold's AI SDK and React Query versions.

```bash
bun add -d @ai-sdk/devtools@1.0.75
bun add -d @tanstack/react-query-devtools@5.97.0
```

In the existing `imports` section of `package.json`, add the `development` line for each tool you installed. Put it before `default` because package import conditions match in order. Production uses the local fallback, including when your install omits dev dependencies.

```json
{
  "imports": {
    "#ai-devtools": {
      "development": "./lib/ai/devtools.js",
      "default": "./lib/devtools-disabled.ts"
    },
    "#query-devtools": {
      "development": "@tanstack/react-query-devtools",
      "default": "./lib/devtools-disabled.ts"
    }
  }
}
```

**AI SDK.** Restart `bun run dev`. Model calls through `getLanguageModel`, such as title generation with the AI Titles plugin installed, record to `.devtools/generations.json`. Run `bun run devtools` in a second terminal from the same app directory to view the recordings. When running the provider directly through EVE outside Next.js, set `NODE_ENV=development` and pass `--conditions=development` to Node.

**React Query.** Set `NEXT_PUBLIC_REACT_QUERY_DEVTOOLS=1` in `.env.local`, then restart `bun run dev`. Open the devtools button on a chat page to inspect the active query cache.

To remove either tool, delete its `development` line and uninstall its package. Keep the `default` entries.
