title: Config Reference
description: Source-owned installation and chat.config.ts runtime configuration
---

`lib/config-schema.ts` defines the configuration contract. `ConfigInput` accepts overrides, while `Config` describes the parsed result with defaults. Import those types from your installed source instead of copying a parallel schema:

```typescript title="config-types.ts"
import type { Config, ConfigInput } from "@/lib/config-schema";

export type AppConfiguration = Config;
export type AppConfigurationInput = ConfigInput;
export type AiConfiguration = Config["ai"];
```

Use `config` from `@/lib/config` for runtime access. See [Configuration](../core/configuration) for a complete input example.

## Installation contract

| Source | Ownership |
| --- | --- |
| `lib/ai/gateway.ts` | Installed gateway implementation |
| `lib/ai/gateway-model-defaults.ts` | Gateway discriminator, defaults, capabilities and environment requirements |
| `lib/storage-provider.ts`, `lib/storage-options.ts` | Installed Files SDK adapter, non-secret options and credential requirements |
| `tools/chatjs/*/chatjs.json` | Installed tool requirements, registration names, exclusive provider slots and document kinds |
| `tools/chatjs/providers.ts` | Shared search, retrieval, media and code-execution provider registrations |
| `tools/chatjs/custom-tools.ts`, `custom-ui.ts` | User-authored tool and renderer registrations |
| `features/*/chatjs.json`, generated feature registrations | Installed uploads, MCP and telemetry contributions |

Tools can declare `requiresTools`, `requiresGateway` (`image` or `video`) and `requiresStorage`. Features can declare `requiresFeatures` and `requiresStorage`. Provider slots and document kinds are exclusive. The planner validates the complete resulting installation, including existing tools during replacement. Declared external capabilities still need adapter and lifecycle tests.

## AI policy

| Input | Meaning |
| --- | --- |
| `ai.gateway` | Literal discriminator of the installed gateway, not a provider switch |
| `ai.curatedDefaults`, `anonymousModels`, `disabledModels` | Model menus and access policy |
| `ai.providerOrder` | Provider ordering in the model selector |
| `ai.workflows.chat`, `title`, `pdf`, `chatImageCompatible` | Shared workflow model defaults |
| `ai.tools.followupSuggestions.enabled`, `.default` | Follow-up generation policy and model |
| `ai.tools.text.polish`, `code.edits`, `sheet.format`, `sheet.analyze` | Document model defaults |
| `ai.tools.image.default`, `video.default` | Optional media model defaults for a capable gateway |
| `ai.tools.deepResearch.defaultModel`, `finalReportModel` | Research model defaults |
| `ai.tools.deepResearch.allowClarification` | Clarification policy |
| `ai.tools.deepResearch.maxResearcherIterations` | Integer from 1 through 10 |
| `ai.tools.deepResearch.maxConcurrentResearchUnits` | Integer from 1 through 20 |
| `ai.tools.deepResearch.maxSearchQueries` | Integer from 1 through 10 |

Search, retrieval, execution, media and research availability come from installed source. They have no `enabled` input. Built-in gateway choices are Vercel, OpenRouter, OpenAI, OpenAI Compatible and LiteLLM. External gateway registry items supply their own discriminator and defaults. Model IDs and upstream availability must be checked with the selected provider.

## Application policy

| Input | Meaning |
| --- | --- |
| `features.parallelResponses` | Enable multiple independent responses, defaults to `true` |
| `authentication.github`, `.google`, `.vercel` | OAuth provider toggles with matching credentials |
| `anonymous.credits`, `.availableTools`, `.rateLimit` | Guest credits, tool access and request limits |
| `attachments.maxBytes`, `.maxDimension`, `.acceptedTypes` | Limits for installed uploads |
| `desktopApp.enabled` | Desktop integration policy for an Electron installation |
| `appName`, `appTitle`, `appPrefix`, `appDescription`, `appUrl` | Product identity and URLs |
| `organization`, `services`, `legal`, `policies` | Contact details and legal/service disclosures |
| `pricing` | Optional currency and free/pro pricing display content |

Pricing text does not configure payment processing. Guest access limits do not replace a verified retention schedule.

## Environment validation

`bun run check-env` checks base application credentials, the installed gateway/storage/tool/feature requirements and enabled OAuth providers. It also runs before development and production builds. A search installation requires its selected provider's key. Setting the other search provider's key does not change the installed implementation.

For example, a minimal app omits MCP, uploads, tools and telemetry and needs no credentials for those absent capabilities. Adding MCP requires `MCP_ENCRYPTION_KEY` even before a connector is configured. See [Configuration](../core/configuration) for installation and replacement commands.
