---
title: Evaluations
description: "Write an EVE evaluation against a separate test agent with a fixed reply, run it with the local CLI, and inspect the required assertions."
---

An EVE eval sends a message to an agent and checks the resulting turn. Use one when a change to instructions or a tool should preserve an observable behavior. For the ChatJS interface and application logic, see [Testing](/reference/testing).

## Define a case

Use a test agent configured to accept eval requests and credentials appropriate for that agent. The ChatJS web channel authenticates requests through its application gateway. For a first eval, use a separate EVE test agent with a mock model so the reply is deterministic. See [EVE evaluations](https://eve.dev/docs/evals) for agent setup and authentication options.

In the separate test agent, keep an instruction file such as `agent/instructions.md` containing “Report your status when asked.” Set a fixed response in the agent configuration.

```ts title="agent/agent.ts"
import { defineAgent } from "eve";
import { mockModel } from "eve/evals";

export default defineAgent({ model: mockModel("ready") });
```

Create an `evals/` directory alongside that agent's `agent/` directory. Add the suite configuration.

```ts title="evals/evals.config.ts"
import { defineEvalConfig } from "eve/evals";

export default defineEvalConfig({});
```

Add a case. This example expects a test agent configured to reply with the word `ready`.

```ts title="evals/readiness.eval.ts"
import { defineEval } from "eve/evals";
import { includes } from "eve/evals/expect";

export default defineEval({
  async test(t) {
    const turn = await t.send("Report your status.");
    t.succeeded();
    t.check(turn.reply, includes("ready"));
  },
});
```

## Run the case

From the test agent's root, use its installed EVE CLI.

```bash
bunx eve eval readiness
```

The filename supplies the case ID. A failed required assertion makes the command exit unsuccessfully. For a tool regression, assert the expected tool call with `t.calledTool(...)`. For subjective quality, EVE also supports model-graded assertions. See [EVE eval assertions](https://eve.dev/docs/evals/assertions).
