Use the ChatJS registry to install editable source and the dependencies required by your selected extensions. shadcn distributes and installs items. The ChatJS CLI configures the app and generates tool registrations from installed descriptors.

## Categories

Choose a category based on what you want to change in your app.

| Category | App behavior | Start here |
| --- | --- | --- |
| Gateways | Select or replace the AI backend | [Choose a gateway](/gateways/overview) |
| File Storage | Select or replace the file storage adapter | [Choose storage](/storage) |
| Sandboxes | Select execution infrastructure for tools and supported persistent EVE sessions | [Configure sandboxes](/deployment/sandboxes) |
| Tools | Add server tools and their result renderers to an existing app | [Install tools](/tools/install) |
| Plugins | Add optional app capabilities and integrations | [Choose plugins](/plugins/overview) |

Select providers during `create` or change them later with `add`. Use `--gateway`, `--storage-provider`, or `--sandbox-provider` to select the provider, and pass `--replace` when switching an installed provider. For tools and plugins, run `chat-js add <item>` and follow the item’s setup instructions. See [add](/cli/add) for options and examples.

## Agent categories and app plugins

In Create, tools belong under **Agent → Tools** and Deep Research under **Agent → Extensions**. This placement is independent of **Source: ChatJS** and **Requires ChatJS**. Image/video generation and file publication require application services. Research runs independently and can optionally use ChatJS presentation.

Image, video and spreadsheet viewers remain optional **Plugins**. Sharing is a plugin and Desktop is under **Setup → Platforms**. Installing a generation or publication tool does not install a viewer.

The native EVE distribution under `dist/r/eve/` excludes application presentation and services. It supports ordinary tool modules and bundles of native agent files, including Deep Research. See [Deep Research](/tools/deep-research) for its two installation options.

## Source and ownership

| Location in the repository | Responsibility |
| --- | --- |
| `packages/registry/src/gateways/<id>/gateway.ts` | Canonical gateway implementations |
| `packages/registry/src/storage/<id>/storage-provider.ts` | Canonical storage adapter entry points |
| `packages/registry/src/tools/<id>/` | Canonical tools and renderers |
| `packages/registry/registry-items.ts` | Media tool definitions and collection of installable items |
| `packages/registry/registry.ts` | Assemble the item and storage catalogs and validate the registry |
| `packages/registry/dist/r/` | Generated registry JSON for distribution |
| `apps/chat/chatjs/core/gateway/` | Shared gateway source copied into every generated app |
| `packages/cli/` | App creation, installation, and registration generation |
| `apps/chat/` | Working reference app and app template source |

Author and test TypeScript source. The registry build serializes metadata and runs shadcn to embed that source in distributable JSON. Do not edit generated JSON.

Your app owns the installed source. Its selected gateway occupies `chatjs/providers/gateway.ts`. Built-in registry tools coexist under `chatjs/tools/<id>/`. Keep manual tool registrations in `integrations/tools/execution.ts` and `integrations/tools/ui.ts`, leaving `tools.ts` and `ui.ts` to the generator. Product tools under `tools/platform/` remain part of the app.
