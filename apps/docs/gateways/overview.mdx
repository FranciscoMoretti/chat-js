ChatJS uses a **gateway** to discover models and route chat requests through the selected backend. Built-in media tools use the gateway when it supports them. Install a gateway with the CLI to select its source, model defaults and credentials. `ai.gateway` must match the installed provider.

## Choose a gateway

| Gateway | Where models come from | Connection settings | Built-in media tools |
| --- | --- | --- | --- |
| [Vercel AI Gateway](/gateways/vercel) (default) | Vercel's multi-provider catalog | `AI_GATEWAY_API_KEY` or Vercel OIDC | Image and video |
| [OpenRouter](/gateways/openrouter) | OpenRouter's multi-provider catalog | `OPENROUTER_API_KEY` | No image or video tool |
| [OpenAI](/gateways/openai) | Your OpenAI account | `OPENAI_API_KEY` | Image |
| [LiteLLM](/gateways/litellm) | Models configured on your proxy | `LITELLM_BASE_URL` and a key if required | No built-in image or video tool |
| [OpenAI Compatible](/gateways/openai-compatible) | Models exposed by your compatible endpoint | `OPENAI_COMPATIBLE_BASE_URL` and a key if required | Image, if supported by the endpoint |

Media generation also requires installing the tool and configuring durable storage. To package a different backend, see [Custom gateway](/gateways/custom).

## Configuration

Select the gateway when creating an app.

```bash
bunx chat-js@beta create my-chat --gateway openrouter
```

To switch an existing app, run this from its root.

```bash
bunx chat-js@beta add --gateway openrouter --replace
```

Replacement preserves runtime overrides. Review model IDs for the new provider and its supported media capabilities. Editing only `ai.gateway` cannot install a new implementation. See [Configuration](/core/configuration).

## Model discovery

The installed adapter queries the gateway at runtime. ChatJS caches the returned catalog for one hour. After switching providers, start your app, open the model picker, and send a message with a model served by the new gateway. See [model discovery and picker settings](/customization/models#model-discovery).
