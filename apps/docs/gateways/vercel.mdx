The Vercel gateway connects ChatJS to [Vercel AI Gateway](https://vercel.com/docs/ai-gateway), which routes requests to models from multiple providers.

This is the **default** gateway.

## Setup

### On Vercel (zero-config)

Vercel deployments get AI Gateway access automatically via OIDC. No API key needed.

### Self-hosted or local dev

1. Go to [Vercel AI Gateway](https://vercel.com/ai-gateway)
2. Create an API key
3. Add to `.env.local`:

```bash
AI_GATEWAY_API_KEY=your_key_here
```

### Config

Install the gateway source (add `--replace` when another gateway is installed):

```bash
bunx chat-js@beta add --gateway vercel
```

The CLI sets the gateway in `chat.config.ts`. Review any existing workflow model IDs against the new provider’s catalog. See [model configuration](/customization/models).

## Authentication

The gateway authenticates using one of these (checked in order):

| Variable             | When                             |
| -------------------- | -------------------------------- |
| `AI_GATEWAY_API_KEY` | Self-hosted or local development |
| `VERCEL_OIDC_TOKEN`  | Automatic on Vercel deployments  |

## Available Models

ChatJS fetches the catalog at runtime and caches it for one hour. Available models depend on the catalog and eligibility for your team.

## Image Generation

The Vercel gateway supports dedicated image models (e.g., `bfl/flux-pro-1.1`) through `createImageModel()`. This enables the built-in [Image Generation](/tools/generate-image) feature.
