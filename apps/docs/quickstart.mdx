Use the `alpha` CLI tag for ChatJS 1.0. APIs and generated source can change during the alpha.

## 1. Create the app

Install Node.js 24 or newer. This walkthrough uses npm. Have a PostgreSQL database ready, with a direct or session connection for local workflows. You will also need access to your chosen AI gateway and credentials for at least one OAuth provider.

```bash
npx chat-js@alpha create my-app
cd my-app
cp .env.example .env.local
```

Choose **Create with current settings** to review the defaults. Menu sections match the [app builder](https://www.chatjs.dev/create). Open **Setup** to change the model gateway, file storage, or sign-in providers. The defaults include Vercel Blob, so you can choose temporary file storage in Setup if you do not need persistent files.

## 2. Configure your services

Use the generated `.env.example` and the CLI's checklist to fill in `.env.local`. The required provider variables depend on what you installed.

| Setting | What to supply |
| --- | --- |
| `DATABASE_URL` | Your PostgreSQL connection string. Local EVE workflows use this connection by default. Set `WORKFLOW_POSTGRES_URL` if you need a separate direct or session connection. [Database setup](/reference/database#eve-workflow-database) |
| `AUTH_SECRET` and `EVE_GATEWAY_SECRET` | Two different secrets. Run `openssl rand -base64 32` once for each value. |
| AI gateway settings | The credentials or endpoint for your installed provider. [Gateway setup](/gateways/overview) |
| OAuth credentials | The client ID and secret for each enabled provider. Register its callback, for example `http://localhost:3000/api/auth/callback/github` for GitHub. [Authentication setup](/customization/authentication) |
| Optional capabilities | The storage, sandbox, or plugin credentials listed for your selections. [Environment variables](/reference/env-vars) |

The integrated EVE worker uses the local app origin by default. Leave `EVE_INTERNAL_ORIGIN` unset for this walkthrough.

## 3. Initialize and run

From the app directory, initialize the application and workflow schemas, then start the development server.

```bash
npm run setup
npm run dev
```

Open `http://localhost:3000`, sign in, and send a message. Once you see the reply, reload the page and reopen the chat from the sidebar to check that the conversation was saved.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| A required variable is missing | Compare `.env.local` with the generated example, run `npm run check-env`, and restart the dev server. |
| Workflow setup fails | Check that the workflow connection reaches PostgreSQL directly or through a session pooler and has the [required privileges](/reference/database#eve-workflow-database). |
| OAuth rejects the redirect | Match the exact scheme, host, port, and provider callback path registered with the OAuth provider. |
