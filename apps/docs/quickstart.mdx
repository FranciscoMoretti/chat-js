## Prerequisites

Install **Node.js 24+** and a package manager: npm, yarn, pnpm, or Bun.

## 1. Create your project

```bash
npx @chat-js/cli@latest create my-app
cd my-app
```

Choose your AI gateway, features, and authentication providers. The CLI generates `chat.config.ts` and lists the credentials your choices require.

## 2. Configure environment variables

```bash
cp .env.example .env.local
```

Fill in `.env.local` using the generated example. You need:

| Setting | Setup guide |
| --- | --- |
| Application and EVE workflow database connections | [PostgreSQL setup](./reference/database#eve-workflow-database) |
| AI gateway credentials | [Gateways](./gateways/overview) |
| Authentication provider credentials and secrets | [Authentication](./core/authentication) and [environment variables](./reference/env-vars) |
| Credentials for any optional features you selected | [Environment variables](./reference/env-vars) |

For the default local port, keep `APP_URL` and `EVE_INTERNAL_ORIGIN` set to `http://localhost:3000`. Generate independent values for `AUTH_SECRET` and `EVE_GATEWAY_SECRET` with `openssl rand -base64 32`.

## 3. Initialize the databases

For fresh local PostgreSQL databases, run:

```bash
npm run db:migrate
npm run eve:db:setup:local
```

Using hosted PostgreSQL, such as Neon? Follow the [hosted workflow setup](./reference/database#hosted-workflow-database) instead of the local-only second command. This initialization is required once per fresh database.

## 4. Start the app

```bash
npm run dev
```

Open `http://localhost:3000` and send a message. The development server starts EVE automatically.

Customize features and branding in `chat.config.ts`. See [Configuration](./core/configuration) when you're ready to make changes.

## Troubleshooting

<Accordion>
  <AccordionItem title="Missing environment variables error">
    ChatJS validates env vars at build time. Check `.env.local` has all required
    variables and restart the dev server.
  </AccordionItem>
  <AccordionItem title="Database connection failed">
    Verify `DATABASE_URL` is correct and the database is running. For local
    PostgreSQL, check the service is started.
  </AccordionItem>
  <AccordionItem title="OAuth redirect error">
    Make sure the callback URL in your OAuth app matches exactly. For local dev,
    use `http://localhost:3000/api/auth/callback/{provider}`.
  </AccordionItem>
</Accordion>

<Accordion>
<AccordionItem title="Optional Features">

| `LANGFUSE_SECRET_KEY` | LLM observability | [Langfuse](https://langfuse.com) |
